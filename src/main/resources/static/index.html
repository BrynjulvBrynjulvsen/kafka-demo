01

Repeat a key

With the same partition count and default partitioner, the same key selects the same partition.

02

Change the key

Different keys can share a partition. Try several; do not expect one partition per key.

03

Leave it empty

A null key lets the producer choose. Batching means this is not necessarily round-robin.

Look for ordering within a partition. Offsets from different partitions are not a global sequence.
